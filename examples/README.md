# Example book

`scandalinbohemia/` is a short story ready to open in Luna without running BookNLP yourself: Arthur Conan Doyle, *A Scandal in Bohemia* (1891), which is in the public domain.

It holds the text (`scandalinbohemia.txt`) and the files [BookNLP](https://github.com/booknlp/booknlp) wrote for it (`.tokens`, `.entities`,
`.quotes`, `.supersense`, `.book`), post-clean up with the Luna editor. Luna never changes the original files: your corrections go to a working copy and can be exported.

To try it, start Luna, open **Settings → Folders with BookNLP output → Add a folder…** and choose this `examples` folder. The book is listed
with its text already found; choose "Start editing".
